# A-Data-Driven-Generalizability-Approach-for-DDoS-Detection-Using-LSTM
Deep learning–based system for detecting DDoS attacks in software-defined networks using LSTM. The model analyzes sequential network traffic from the CICDDoS2019 dataset and compares performance with traditional machine learning classifiers.

<h1>DDoS Detection Using LSTM</h1>

<p>
This project implements a deep learning based system for detecting distributed denial-of-service (DDoS) attacks in software-defined networks. An LSTM model is used to analyse sequential network traffic patterns from the CICDDoS2019 dataset and classify traffic as normal or malicious.
</p>

<h2>Features</h2>
<ul>
    <li>DDoS attack detection using LSTM</li>
    <li>Network traffic preprocessing and feature selection</li>
    <li>Comparison with traditional machine learning models</li>
    <li>Evaluation using accuracy, precision, recall and F1-score</li>
</ul>

<h2>Technologies Used</h2>
<ul>
    <li>Python</li>
    <li>TensorFlow and Keras</li>
    <li>Scikit-learn</li>
    <li>Pandas and NumPy</li>
</ul>

<h2>Dataset</h2>
<p>
CICDDoS2019 dataset
</p>

<h2>Usage</h2>
<p>
Run data preprocessing scripts, train the LSTM model, and evaluate performance using the provided source files.
</p>
